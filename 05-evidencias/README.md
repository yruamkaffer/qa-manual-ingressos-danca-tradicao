# Evidências dos Testes

Este diretório armazena as evidências coletadas durante a execução dos testes manuais do sistema Ingressos Dança e Tradição.

Todas as evidências foram capturadas em ambiente de homologação, utilizando massa de teste fictícia.

Nenhum dado pessoal real foi utilizado durante os testes.

## Organização

- `smoke-test/`: evidências do smoke test
- `casos-de-teste/`: evidências dos casos de teste funcionais
- `bugs/`: evidências dos bugs encontrados
